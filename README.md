# Around The U.S. 📸

Una plataforma web interactiva diseñada como un portafolio de fotografía dinámico, donde los usuarios pueden explorar paisajes icónicos de los Estados Unidos, interactuar con el contenido y personalizar su perfil.

---

## 🚀 Descripción del Proyecto

**Around The U.S.** es un proyecto interactivo desarrollado durante mi aprendizaje en desarrollo web front-end. El objetivo principal de esta etapa del proyecto es migrar de un diseño estático (con elementos HTML fijos o _hardcoded_) a una aplicación dinámica capaz de renderizar e interactuar con datos en tiempo real utilizando JavaScript vanilla.

Actualmente, el proyecto procesa un conjunto de tarjetas de forma dinámica a partir de una base de datos local (un array de objetos), preparando la estructura para futuras interacciones del usuario, como la edición de perfiles y la adición de nuevos lugares a través de ventanas emergentes (popups).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio web.
- **CSS3:** Diseño responsivo y estilos basados en la metodología **BEM** (Block, Element, Modifier) para mantener un código limpio y escalable.
- **JavaScript (ES6+):** Manipulación dinámica del DOM, recorrido de arreglos (`forEach`), y lógica de componentes interactivos (en desarrollo).

---

## ✨ Características y Funcionalidades (Sprint Actual)

- **Renderizado Dinámico:** Transición de tarjetas estáticas a una estructura basada en datos manipulados desde `index.js`.
- **Diseño Responsivo:** Interfaz adaptada para una visualización óptima tanto en dispositivos móviles como en pantallas de escritorio.
- **Estructura del DOM Preparada:** Inclusión de modales/popups listos para ser controlados mediante eventos de JavaScript en los próximos sprints (Editar Perfil, Añadir Tarjeta y Vista de Imagen Completa).
